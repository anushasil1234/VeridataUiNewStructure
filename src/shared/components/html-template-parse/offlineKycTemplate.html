details of Aadhaar Offline Verification

Q.1

What is Aadhaar offline Verification?

An eKYC XML file containing the personal data, required for verification, can be downloaded only by you using your Aadhar credentials.
This file contains the name, date of birth and gender, besides other information, that would be extracted to match with the information provided by you.
The process would first inspect the authenticity of the eKYC XML file provided by you and then perform the matching and then dispose the file.

steps for Aadhaar Offline Verification file

STEP

01

Go to MyAadhaar site

Click MyAadhaar, the official website to get details of offline verication.

STEP

02

Login

Log in by entering your Aadhaar Number and OTP (OTP is sent to the UIDAI registered mobile number).

STEP

03

offline eKYC

After Logging in to the site, click on the ‘offline eKYC’ widget (bottom left).

STEP

04

Generate Share Code

A 4-digit share code of your choice to be entered and then press download, a zip file will be downloaded in your default download folder

STEP

05

Upload file in Veridata

Please, upload the zip folder along with the share code in Veridata
